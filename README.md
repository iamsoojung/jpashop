## 프로젝트 개요

📌 **목표**: 스프링 부트와 JPA를 활용한 웹 애플리케이션을 단계적으로 설계, 개발

📌 **주요 기술 스택**:
  - **Back-end**: Spring Boot, JPA, Hibernate
  - **Front-end**: Thymeleaf
  - **Database**: H2 Database

---

## 실행 방법

1. 프로젝트 클론
   ```bash
   git clone https://github.com/iamsoojung/jpashop.git
   ```
2. 프로젝트 빌드 및 실행
   ```bash
   ./gradlew bootRun
   ```
3. 애플리케이션 접속
   브라우저에서 [http://localhost:8080](http://localhost:8080) 접속
